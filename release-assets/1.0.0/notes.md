# Twirlmate 1.0.0 Release Assets

Use this folder as the local source of truth for store-listing assets tied to the 1.0.0 launch build.

Related file:

- [release-assets/1.0.0/screenshot-capture-checklist.md](/Users/njhmagyar/Documents/twirlmate/twirlmate-mobile/release-assets/1.0.0/screenshot-capture-checklist.md)

## Filename Convention

Put platform before the screen name:

- `01-ios-events-discovery.png`
- `02-ios-event-detail.png`
- `03-ios-coaches-discovery.png`
- `01-android-events-discovery.png`

Use the same numbering order across iOS and Android whenever the story is the same.

## Folder Layout

- `ios/raw/`: untouched captures from the iPhone release candidate build
- `ios/final/`: selected and edited iPhone screenshots ready to upload
- `android/raw/`: untouched captures from the Android emulator or device
- `android/final/`: selected and edited Android screenshots ready to upload

## Recommended Capture Order

1. `01-<platform>-events-discovery.png`
2. `02-<platform>-event-detail.png`
3. `03-<platform>-coaches-discovery.png`
4. `04-<platform>-coach-detail.png`
5. `05-<platform>-groups-discovery.png`
6. `06-<platform>-group-detail.png`

Optional:

1. `07-<platform>-home.png`
2. `08-<platform>-event-search.png`
3. `09-<platform>-state-browsing.png`
4. `10-<platform>-dark-mode.png`

## Capture Notes

- Use a release candidate build whenever possible.
- Prefer records with strong imagery and clear community context.
- Avoid loading spinners, empty states, debug UI, and broken content.
- Keep the status bar clean and consistent.
- If final uploaded screenshots differ from raw captures, note why here.
